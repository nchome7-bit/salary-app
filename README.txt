給与管理アプリ UI整理版 v5

使い方
1. ZIPを展開し、salary-app-v5フォルダーを開きます。
2. index.htmlをブラウザーで開きます。assetsフォルダーは一緒に保管してください。
3. ローカルファイルを開けない環境では、VS CodeのLive Serverなどで配信してください。
   Pythonがある場合は、このフォルダーで次のコマンドを実行できます。
   python3 -m http.server 8000

ファイル構成
index.html             画面とフォーム
assets/css/style.css   レイアウト・Safari向けの入力欄調整
assets/js/script.js    給与計算・勤務登録・ブラウザー内保存
README.txt             この説明

整理した内容
・勤務日と編集画面の日付入力の幅・文字位置を調整
・表示する月を年／月の選択欄に統一
・320pxからPC画面までの幅でレイアウトを調整
・カレンダーの狭い画面での表示を維持
・キーボード操作時のフォーカス表示と通知を改善
・勤務編集時の空の日付／同じ出退勤時刻を防止
・CSS／JavaScriptをassets内に整理し、キャッシュ用バージョンをv5に更新

データについて
保存キーと既存データ形式はv4と同じです。
勤務と設定はブラウザーのlocalStorageに保存します。
同じブラウザー・同じ配信元で使う場合は、既存データを引き継ぎます。
別のブラウザー、別のURLやローカルファイルへの移動では引き継がれない場合があります。
このZIPには勤務データやテスト用の登録データは含みません。

確認した内容
Chromiumで320／375／390／430／768／1280pxの表示幅を確認。
勤務登録、月の切り替え、勤務編集、時給変更、再読み込み後の保存を確認。
JavaScript構文と実行エラーがないことを確認。
Safari向けCSSを調整していますが、Safari実機での表示確認は未実施です。
